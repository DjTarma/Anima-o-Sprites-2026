# Animação Sprites [Felpudo e Fofura] 2026.2
Projeto desenvolvido por Samuel Santos Figueirêdo para a Universidade Estadual da Bahia (UNEB)

## Descrição
Cena 2D com diversos limites físicos (Rigidbody 2D, etc) para testar o funcionamento de um trigger de partícula.
Esta cena possui foco para condições de vitória.

## Comandos de movimentação:
-	Walk (andar):		WASD
-	Pulo			Space
-	Reiniciar:		R
